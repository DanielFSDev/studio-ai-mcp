# studio-ai-mcp

MCP server for Roblox Studio — AI-powered game development tools.

## Overview

This repository contains a custom MCP (Model Context Protocol) server for Roblox Studio, designed to enable AI agents to interact with Roblox Studio programmatically.

## Features

- Script reading, searching, and editing
- Game tree exploration and instance inspection
- Play Test automation
- Console output monitoring
- Asset management
